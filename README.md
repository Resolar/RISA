# RIAS group meeting presentation

This branch contains the presentation prepared for a 15-minute group meeting:

- `deliverables/RIAS_group_meeting_15min.pptx`: editable PowerPoint with speaker notes
- `deliverables/RIAS_group_meeting_15min.pdf`: rendered PDF preview
- `deliverables/RIAS_group_meeting_speaker_script_15min.pdf`: A4 speaker script with timing, transitions, and Q&A
- `deliverables/RIAS_group_meeting_speaker_script_15min.docx`: editable speaker script

The deck covers 2026 vision-language and industrial anomaly detection research directions, followed by a detailed review of *Referring Industrial Anomaly Segmentation* (RIAS).
